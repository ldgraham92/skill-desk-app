# Community conduct

Be respectful, constructive and specific. Discuss the work without attacking the person. Welcome contributors with different backgrounds and levels of experience.

Harassment, threats, discriminatory language, sexualized conduct, doxxing, and publishing another person's private information are not acceptable. These expectations apply to issues, pull requests, discussions, and other project spaces.

Report abusive content using GitHub's reporting controls. Repository maintainers may edit or remove content, close discussions, or restrict participation to protect the community. Apply these rules consistently, including to maintainers.
