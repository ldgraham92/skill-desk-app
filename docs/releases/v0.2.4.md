# Skill-Desk 0.2.4

Move skills between devices with Manage → Export package and Import package. Select skills, review included files, save to Downloads, then transfer the ZIP by USB, shared folder or a tool such as LocalSend. No Skill-Desk server or account is required.

Imports preserve full skill folders, validate checksums and paths, and let you select a destination provider. Existing skills are never overwritten. Review instructions for private content and platform-specific requirements before sharing or installing. This is manual package transfer, not automatic synchronization.

This release also removes the old personal seed catalog, makes the public root the marketing site, fixes its provider indicator, and adds source-build and deployment guides. Older releases retain their original contents.

Windows publisher signing and macOS notarization remain unconfigured. Updater signatures are separate and verified by the application.
