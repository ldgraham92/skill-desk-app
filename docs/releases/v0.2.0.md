Introduces signed in-app updates. This is the one-time manual upgrade from 0.1.x; future published versions appear inside Skill-Desk.

## Included

- Updates button beside Print and a tray menu entry.
- Native release notes, download progress, retry controls, and Update and restart.
- Automatic checks at most once daily, with manual checks on demand.
- Signature verification before installing any update.
- Installation waits for active skill jobs, description generation, and outstanding previews.
- Windows per-user installer, macOS application updates, and Linux AppImage updates.

The .deb remains available for package-manager installation. Use AppImage for in-app Linux updates. Your skills, preferences, and CLI sign-ins remain outside the app installation.

Updater signatures verify the update source. Operating-system publisher signing and macOS notarization are not configured, so publisher warnings may still appear for manual downloads.
