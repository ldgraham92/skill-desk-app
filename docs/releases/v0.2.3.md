# Skill-Desk 0.2.3

Fix the Windows Updates button opening a blank window and freezing the app. The toolbar and tray previously created a WebView2 window synchronously inside an event handler. Window creation now runs on a worker, leaving the event loop free to finish loading it. Repeated clicks coalesce, status requests run asynchronously, and window creation failures produce visible feedback.

Windows CI now launches the built app, opens Updates, waits for its native version status, then closes and reopens it. A hung UI call fails the check instead of allowing the release to publish.

## Installing this fix on Windows

Versions 0.2.0 through 0.2.2 contain the affected window-opening code. If Updates freezes, close Skill-Desk through Task Manager and run this release's Windows installer over the existing installation. You do not need to uninstall or remove your skills. Once this fix is installed, future releases can use the in-app updater.

macOS and Linux packages include the same fix. The existing signed update feed remains in use.
