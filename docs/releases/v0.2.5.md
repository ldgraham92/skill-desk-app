# Skill-Desk 0.2.5

Send skills between Windows, macOS and Linux using Skill-Desk itself. No LocalSend installation, account or hosted service is required.

On the receiver, open Manage → Receive from device. On the sender, export and review selected skills, then choose Send to device. Select the receiver, compare its security code, enter its PIN and request the transfer. The receiving device must accept and then review the package before installing.

Sharing runs only while requested, uses TLS and expires automatically. Manual address entry is available when discovery is blocked. Local-network or firewall permission may be required; this version uses local IPv4 networks. This is package transfer, not continuous synchronization or a general LocalSend client.

Also fixes the Manage list refreshing immediately after package installation.

Automated checks cover two packaged services, explicit acceptance, complete file transfer, import review and listener shutdown on Windows, macOS and Linux. Physical cross-device testing on your network is still needed.

Windows publisher signing and macOS notarization remain unconfigured. The application separately verifies updater signatures.
