# Skill-Desk 0.3.0

This release brings project libraries, agent-specific recommendations, and more ways to try skills and tell us what worked.

- **Projects and personal libraries:** onboard a local Git repository and select Codex or Claude Code before installing. Existing files are never overwritten; Skill-Desk does not commit or push your project changes.
- **AI Hero and PStack:** browse 84 bundled skills, including nested upstream folders, with supporting files and licenses included.
- **Recommendations:** preview and edit recent user prompts before the selected agent reviews its own history. See what adds value, what is already covered by your library, and a first step to try.
- **Your preferences:** keep project notes, saved suggestions, and dismissals separate by agent and project.
- **Installation history:** review where skills went, assess usefulness, and undo an unchanged installation while keeping an archived copy. Edited or replaced files are preserved.
- **Help and feedback:** a screenshot walkthrough, What's new panel, local agent readiness checks, and feedback previews that open GitHub drafts. There is no background telemetry.
- **Small improvements:** Update Ready in the sidebar and Print Cheatsheet in Quick reference.

Recommendations use your installed CLI's normal service and allowance. History is sampled across the selected agent's projects; deselect unrelated excerpts. No live inference is required for browsing, project onboarding, or Markdown/package imports.

Installation history begins with installs made using this release. Existing skills and saved settings remain in place. Windows publisher signing and macOS notarization are not configured; updater packages use Skill-Desk's release signature.

## Suggested test path

1. Install or update on your OS and open What's new.
2. Check agent readiness and onboard a temporary project repository.
3. Install one bundled skill into that project, then try its starter prompt in the selected agent.
4. Preview usage, edit the sample, and request recommendations when you are ready to use your provider allowance.
5. Save or dismiss a suggestion. Rate an installed skill and try undo on an unchanged test install.
6. Use Send feedback to review and submit a bug report or suggestion.
