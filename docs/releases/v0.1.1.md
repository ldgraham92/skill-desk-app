Replacement desktop preview with repository documentation and attribution corrections. Application behavior is unchanged.

Skill-Desk desktop preview.

## Download

- Windows x64: download the `.exe` installer below. It creates Start menu and desktop shortcuts and uses the Skill-Desk logo in the taskbar and tray.
- macOS: download the `.dmg` matching the architecture in its filename and drag Skill-Desk into Applications.
- Linux x64: download the `.deb` package for a compatible Debian/Ubuntu desktop.

Python is bundled. AI authoring needs an installed, signed-in Codex or Claude Code CLI; GitHub imports need Git. No separate API key or Skill-Desk account is required.

## Included

- Browse personal global skills with searchable, cached reference guidance.
- Create a skill from a brief, review it, and install it globally.
- Import Markdown text/files or a skill folder from GitHub.
- Track installation origins, archive removed skills, and restore them with conflict checks.
- Watch skill file changes and show creation/import progress.
- Persist favorites across desktop launches.
- Use Codex or Claude Code for authoring through its existing CLI login.
- Open or hide the window through the branded tray menu; closing the window or choosing Quit stops the helper.

## Preview limitations

Installers are unsigned, so operating-system publisher warnings are expected. There is no automatic app updater yet. Download future releases from GitHub.

The default desktop library is `~/.agents/skills`. Selecting Claude changes the authoring provider, not the installation location; the server CLI supports `--library claude`. A desktop library selector and curated/user-added library collections are planned.

CI builds and tests the packaged service on each platform. These checks do not replace testing the installed graphical application on a clean Windows or Linux machine. Please report installation and runtime findings through Issues.

`SHA256SUMS.txt` contains checksums of the installers. It verifies file integrity, not publisher identity.
