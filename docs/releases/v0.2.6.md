# Skill-Desk 0.2.6

Package review now shows **Install selected skills (x)** and disables the button when nothing is selected. You can hide duplicate entries while keeping a visible explanation of why they cannot be installed and how to replace the existing copy. Show duplicates again to inspect each conflict.

Finding a receiving device by address selects it automatically and focuses the security-code confirmation. Successful transfers show a clear completion dialog on both devices, with **Close and stop sharing**. The receiver can continue to review the package before installing; closing without review discards it.

Validated with automated transfer tests and browser interaction checks for selection counts, duplicate filtering, address selection, completion dialogs and stop-on-close behavior. Native Windows, macOS and Linux packages are built and tested by the release workflow.

Windows publisher signing and macOS notarization remain unconfigured. The application separately verifies updater signatures.
