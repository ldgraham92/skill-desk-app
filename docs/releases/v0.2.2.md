# Skill-Desk 0.2.2

Skill-Desk now opens in dark mode, with charcoal panels, copper accents, clearer navigation, and polished hover, focus and dialog transitions. The appearance toggle remembers your choice across desktop restarts. Reduced-motion preferences disable animation, and printed guides keep a light background.

The theme covers the library, management dialogs, startup and updater windows, and the portable marketing demo. It uses local CSS and system fonts, with no new runtime dependency or background animation loop.

Prompt copying and quick reference now use the actual skill name and the selected provider: `$skill-name` for Codex, `/skill-name` for Claude Code. Shared folders follow the provider filter. The demo has a separate prompt selector, so choosing an authoring CLI does not silently change copied commands.

The demo also reflects Windows, macOS and Linux packaging, global provider discovery, copying between providers, and signed in-app updates.

## Update

In Skill-Desk 0.2.0 or later, open **Updates**, check for updates, then choose **Update and restart**. Finish or discard pending skill previews first. Older versions need this release's installer once to get the updater. Linux in-app updates require the AppImage build.

Platform installers and signed update packages are attached to this release. Skills and CLI logins stay on your computer.
